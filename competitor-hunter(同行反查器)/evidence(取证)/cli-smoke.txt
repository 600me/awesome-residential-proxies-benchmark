usage: check-proxy-tax [-h] --url URL [--requests REQUESTS] [--marker MARKER]
                       [--price-per-1k PRICE_PER_1K] [--proxy PROXY]
                       [--concurrency CONCURRENCY] [--timeout TIMEOUT]
                       [--json] [--version]

Sample a URL concurrently and report the effective cost per 1,000 usable responses after 403s, 429s, 5xx errors, timeouts, and marker misses.

options:
  -h, --help            show this help message and exit
  --url URL             absolute http(s) URL to probe
  --requests REQUESTS   number of concurrent samples (default: 20)
  --marker MARKER       string that must appear in the response body for a
                        usable sample
  --price-per-1k PRICE_PER_1K
                        nominal price per 1,000 requests in USD (default:
                        0.49)
  --proxy PROXY         HTTP(S) proxy URL, e.g. http://user:pass@host:port
  --concurrency CONCURRENCY
                        maximum in-flight requests (default: 4)
  --timeout TIMEOUT     per-request timeout in seconds (default: 10)
  --json                emit one JSON object for CI/CD pipelines
  --version             show program's version number and exit

examples:
  check-proxy-tax --url https://example.com/product --requests 20 \
      --marker "Add to cart" --price-per-1k 0.49
  check-proxy-tax --url https://example.com --json > report.json

exit codes:
  0  every sampled request was usable
  1  some requests were blocked (degraded)
  2  no request was usable
  3  invalid arguments
