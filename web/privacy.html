Chrome Web Store Policy Compliance

Privacy Policy & Limited Use Disclosure

Last updated: October 16, 2026. Effective for the Proxy Fraud Checker browser extension and associated web benchmark services.

1. Single Purpose & Core Functionality

The Proxy Fraud Checker Chrome extension is built with a singular, clear technical purpose: to allow developers, data engineers, and web scraping specialists to inspect their browser's current public exit IP address, ASN/network type (Hosting vs. ISP candidate), and publicly reported fraud risk signals.

The extension operates strictly on an explicit on-demand basis. Network requests are initiated only when the user opens the extension popup or clicks the "Check again" button. There are no background pollers, persistent alarms, or continuous tracking tasks.

2. Data Collection & Zero Personal Data Storage

We believe in absolute data minimalism. Specifically:

  • No Personal Identifiable Information (PII): We do not collect names, email addresses, phone numbers, physical locations, or payment credentials.
  • No Browsing History or Page Access: The extension does not inspect web pages, DOM elements, cookies, session storage, form inputs, or search queries. No <all_urls>, tabs, webRequest, or storage permissions are requested or used.
  • No Analytics or Tracking SDKs: No third-party analytics (e.g., Google Analytics, Mixpanel, Sentry) or advertising scripts are embedded in the extension.
  • Volatile Memory Only: IP lookup results are held solely in the browser's temporary popup memory and are immediately cleared when the popup is closed.

3. Third-Party Service Providers

To retrieve IP classification metadata, the extension communicates directly over secure HTTPS with the public endpoint https://api.ipquery.io.

When a check is initiated, the IPQuery API necessarily receives your outbound IP address and standard HTTP request headers in order to serve the query response. We do not transmit any additional user tokens, cookies, or tracking headers to IPQuery. Please refer to IPQuery's Privacy Terms for their independent server log retention policies.

4. Affiliate Disclosures & Outgoing Links

The extension and benchmark portal feature promotional links to enterprise proxy infrastructure providers (including Smartproxy, Bright Data, Apify, and Oxylabs). As of October 17, 2026, the Smartproxy / Decodo affiliate link is active; Bright Data and Apify applications remain pending. No exclusive discount code is confirmed.

  • All outgoing promotional links are clearly labeled and execute standard navigation via safe redirect gateways (https://go.272738.xyz/*).
  • All links utilize rel="noopener noreferrer sponsored" attributes. No browsing history or extension user data is passed to partner websites.
  • If a user chooses to purchase a commercial subscription through our recommended links, the publisher may receive an affiliate commission at zero additional cost to the user.

5. Google Chrome Limited Use Compliance

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements:

  • We only use permissions that are directly necessary to deliver the advertised single-purpose user-facing features.
  • We never transfer, sell, or disclose user data to third parties, data brokers, or lending platforms.
  • We never use or transfer user data for personalized advertising or credit determination purposes.
