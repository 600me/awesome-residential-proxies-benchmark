# Cloud and developer tools: runnable cost calculators

Independent, standard-library Python budget worksheets. These are arithmetic tools, not measured performance benchmarks. Rates are user supplied; no live price or coupon is promised. Linked buying guides disclose affiliate links.

## scraperapi

[Repository and buying guide](https://github.com/600me/scraperapi-pricing-coupons) · [Python calculator](https://github.com/600me/scraperapi-pricing-coupons/blob/main/scraperapi_calculator.py)

```sh
python3 scraperapi_calculator.py --units 100 --unit-rate 0.5 --base 10 --one-time 100 --annual-base 100
```

Illustrative first-year monthly billing: $820; annual base alternative: $800. Replace every rate and usage input with your actual quote.
